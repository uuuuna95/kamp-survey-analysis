# KAMP 설문조사 결과 분석

KAMP에서 실시한 설문의 **엑셀 원본(로데이터)** 과 **설문 문항 파일** 두 개를 올리면, 문항 유형에 맞게 결과를 정리해 주는 웹 앱(PoC)이에요.
문항 20개 기준 약 60분 걸리던 손 집계를 5분 이내로 줄이는 것이 목표예요.

- **배포 주소:** https://kamp-survey-analysis.vercel.app
- **기획 문서:** [PRD.md](PRD.md) (무엇을 왜 만드는지) · [PLAN.md](PLAN.md) (작업 순서와 성공 기준) · [DESIGN.md](DESIGN.md) (설계) · [DEPLOY.md](DEPLOY.md) (배포 안내)

## 무엇을 해 주나요

| 기능 | 내용 |
|---|---|
| 자동 집계·차트 | 문항 유형(객관식 / 주관식·서술형)을 추정하고, 객관식은 보기별 응답 수·비율(합계 100.0%)·가로 막대 차트, 주관식·서술형은 응답 목록을 보여 줘요. 중복응답(`1,3`), 기타(직접 입력), 무응답을 따로 세요. |
| AI 해석 | 객관식은 문항마다 2~3문장 해석, 주관식·서술형은 답변을 관점별로 나눠 주요 의견 3~5개로 묶어요(의견별 건수는 앱이 직접 셈). 집계에 없는 숫자는 쓰지 않도록 검사해요. |
| 직접 고치기 | 추정한 문항 유형을 바꾸거나, 분석에서 뺀 열을 "문항으로 되돌리기" 할 수 있어요. 판단이 애매한 문항에는 "확인 필요"를 붙여요. |
| 참여자 정보·집단별 집계 | 분석 시작 전에 참여자 정보(이름·사번·부서·직급·직위·직책)를 결과에 반영할지(기본: 아니오), 부서별·직급별로 나눠 볼지 골라요. 나눠 보면 "③ 문항별 결과" 아래에, 객관식 보기 응답 비율이 다른 집단보다 30%p 이상 높은 경우만 "○○부의 답변이 n%로 특히 높게 나타났습니다"처럼 알려 줘요(앱이 직접 셈). 참여자 정보는 AI에 보내지 않아요. |
| 엑셀 내려받기 | 버튼 한 번으로 시트 3개(문항별 요약 / 객관식 결과+차트+해석 / 주관식·서술형 결과)가 담긴 엑셀을 내려받아요. 부서별·직급별로 나눠 봤다면 "부서별 경향"·"직급별 경향" 시트가 따로 더해지고, 같은 문장이 들어가요. 화면과 같은 숫자예요. |

## 올리는 파일 모양

- **엑셀 원본(로데이터)**
  - 첫 줄은 열 제목, 그 아래는 응답자 한 명당 한 줄
  - A~G열: 참여일, 이름, 사번, 부서, 직급, 직위, 직책 (A열은 쓰지 않고, B~G열은 참여자 정보)
  - H열부터: 열 제목이 `문항번호1`, `문항번호2`… (뒤의 숫자가 문항 번호)
  - 객관식 응답은 보기 번호(중복응답은 `1,3`), 주관식·서술형은 글
- **설문 문항 파일(엑셀)**
  - 문항 제목: 굵은 글씨로 `1. 질문` (번호가 엑셀 원본 `문항번호1`의 숫자와 짝)
  - 객관식 보기: 문항 제목 아래 굵지 않은 글씨로 한 줄에 하나씩. 위에서부터 1, 2, 3…번 보기 (원본의 응답 숫자)
  - 주관식·서술형: 보기 줄 없이 바로 다음 굵은 글씨 문항 제목이 이어짐
- 한글 파일(.hwp)은 읽지 않아요. 엑셀(.xlsx)로 옮겨서 올려 주세요.
- 예시(가짜) 파일: [`tests/fixtures/`](tests/fixtures/) (`예시 원본.xlsx`, `예시 문항.xlsx`, 손으로 계산한 `정답표.md`)

## 개인정보와 보안

- 올린 엑셀 파일은 **서버로 보내지 않고 브라우저에서만** 읽고, 집계하고, 엑셀로 만들어요.
- 서버로 가는 것은 "AI 해석 만들기"를 눌렀을 때의 해석 요청(문항 질문, 객관식 집계 숫자, 주관식·서술형 답변 글)뿐이고, 서버는 이를 저장하거나 로그로 남기지 않아요.
- AI 해석은 **공유 비밀번호**가 맞을 때만 받을 수 있고, 요청 크기·문항 수에 상한이 있어요.
- 외부 AI(OpenAI)로 응답이 전송되므로, 실제 설문 데이터는 사내 보안 정책에서 허용되는지 확인한 뒤에 쓰세요.

## 내 컴퓨터에서 실행하기

필요한 것: Node.js 20 이상

```bash
npm install
```

`.env` 파일을 만들고 아래 값을 넣어요(이 파일은 Git에 올라가지 않아요).

| 이름 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | 필수 | OpenAI API 키 (AI 해석용) |
| `ACCESS_PASSWORD` | 필수 | AI 해석을 받을 때 입력하는 공유 비밀번호 (영문·숫자·기호) |
| `OPENAI_MODEL` | 선택 | 쓸 모델 이름. 비우면 `gpt-4o-mini` |

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 열어요.

## 확인 명령어

```bash
npm test
```

```bash
npm run lint
```

```bash

```

`npm test`는 예시 데이터와 정답표로 집계 규칙, AI 해석 규칙(가짜 AI 사용), 엑셀 내용, 성공 기준 SC-1~8을 자동으로 확인해요.

## 기술

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · ExcelJS(엑셀 읽기·만들기) · Chart.js(차트) · OpenAI API(AI 해석, 서버에서만 호출) · Vitest(자동 테스트) · Vercel(배포)

## 폴더 구성

```
src/app/page.tsx              화면 (올리기 → 한눈에 보기 → 문항별 결과 → 뺀 열)
src/app/api/interpret/        AI 해석 서버 주소 (유일한 서버 코드)
src/components/               화면 부품 (업로드, 문항 카드, 차트 표, AI 해석, 내려받기 등)
src/lib/survey/               파일 읽기·유형 추정·집계·관점 나누기 (브라우저)
src/lib/ai/                   AI 요청 만들기·규칙 검사·OpenAI 호출
src/lib/excel/                결과 엑셀 만들기·차트 그림
tests/                        자동 테스트와 예시 데이터
```
